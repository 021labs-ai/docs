## Overview

RDK automatically calculates the cost of every LLM call based on token usage and provider pricing. Cost data is included in span metadata without any additional configuration.

## How It Works

When RDK captures an LLM call, it:

1. Extracts token usage from the response
2. Looks up the model's pricing (input/output per million tokens)
3. Calculates costs including cache savings
4. Adds the cost breakdown to span metadata

```python
from rdk import init, shutdown
from anthropic import Anthropic

init()

client = Anthropic()
response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Hello!"}]
)

shutdown()
```

The resulting span metadata includes:

```json
{
  "cost": {
    "total_cost": 0.000045,
    "input_cost": 0.000012,
    "output_cost": 0.000033,
    "cache_read_cost": 0.0,
    "cache_write_cost": 0.0,
    "cache_savings": 0.0,
    "currency": "USD"
  }
}
```

## Cost Fields

| Field | Description |
|-------|-------------|
| `total_cost` | Total cost in USD |
| `input_cost` | Cost of input/prompt tokens |
| `output_cost` | Cost of output/completion tokens |
| `cache_read_cost` | Cost of reading cached tokens (discounted rate) |
| `cache_write_cost` | Cost of writing to cache (Anthropic only) |
| `cache_savings` | Amount saved by using cached tokens |
| `currency` | Always `"USD"` |

## Cache Savings

When using prompt caching (Anthropic), RDK calculates how much you saved:

```python
from anthropic import Anthropic
from rdk import init, shutdown

init()

client = Anthropic()

# Long system prompt that will be cached
system_prompt = "You are a helpful assistant..." * 100

# First call - creates cache
response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=500,
    system=[{
        "type": "text",
        "text": system_prompt,
        "cache_control": {"type": "ephemeral"}
    }],
    messages=[{"role": "user", "content": "Question 1"}]
)

# Second call - reads from cache
response = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=500,
    system=[{
        "type": "text",
        "text": system_prompt,
        "cache_control": {"type": "ephemeral"}
    }],
    messages=[{"role": "user", "content": "Question 2"}]
)

shutdown()
```

The second call will show `cache_savings` reflecting the discount from using cached tokens.

## Unknown Models

If RDK encounters a model without pricing data, the `cost` field will be omitted from metadata. Token usage is still captured.

<Note>
Pricing data is updated regularly. If you're using a new model and don't see cost data, check for RDK updates.
</Note>

## Aggregating Costs

To calculate total costs across a trace with multiple LLM calls:

```python
from rdk import observe, get_current_trace, shutdown
from anthropic import Anthropic

@observe(name="multi-step-task")
def process(query: str) -> str:
    client = Anthropic()

    # Multiple LLM calls
    response1 = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=500,
        messages=[{"role": "user", "content": f"Analyze: {query}"}]
    )

    response2 = client.messages.create(
        model="claude-sonnet-4-6",
        max_tokens=500,
        messages=[{"role": "user", "content": f"Summarize: {response1.content[0].text}"}]
    )

    return response2.content[0].text

result = process("Explain quantum computing")
shutdown()
```

Each span has its own cost. Sum `metadata.cost.total_cost` across spans to get the trace total.
