## Signature

```python
def init(
    api_key: str | None = None,
    endpoint: str | None = None,
    batch_size: int = 10,
    flush_interval: float = 5.0,
    timeout: float = 30.0,
    sample_rate: float = 1.0,
    redact_pii: bool = False,
    redactor: Callable[[Any], Any] | None = None,
    debug: bool = False,
    enabled: bool = True,
    on_error: Callable[[Exception], None] | None = None,
    instrument_langchain: bool = True,
    instrument_anthropic: bool = True,
    instrument_openai: bool = True,
    instrument_gemini: bool = True,
    transport: str | None = None,
    test_mode: bool | None = None,
) -> RDK | None
```

<Note>
Calling `init()` is optional. If `RDK_API_KEY` is set in your environment, RDK auto-initializes when `@observe` is first called.
</Note>

## Parameters

<ParamField path="api_key" type="string" default="RDK_API_KEY env var">
  Your RDK API key for authentication. Falls back to the `RDK_API_KEY` environment variable if not provided.
</ParamField>

<ParamField path="endpoint" type="string" default="https://collector.021labs.ai">
  The URL of your trace collector. Falls back to the `RDK_ENDPOINT` environment variable, then the default collector.
</ParamField>

<ParamField path="batch_size" type="integer" default={10}>
  Maximum number of spans to batch before sending.
</ParamField>

<ParamField path="flush_interval" type="float" default={5.0}>
  Maximum seconds between automatic flushes.
</ParamField>

<ParamField path="timeout" type="float" default={30.0}>
  HTTP request timeout in seconds.
</ParamField>

<ParamField path="sample_rate" type="float" default={1.0}>
  Fraction of traces to capture (0.0 to 1.0). `1.0` captures all traces.

  Example: `0.1` captures 10% of traces.
</ParamField>

<ParamField path="redact_pii" type="boolean" default={false}>
  If `True`, automatically redact common PII patterns (emails, phones, SSNs, credit cards, API keys) before sending traces.

  For custom redaction, use `redactor` instead.
</ParamField>

<ParamField path="redactor" type="Callable[[Any], Any]" default="None">
  Custom redaction function applied to span inputs and outputs before sending.

  Use `create_redactor(RedactorConfig(...))` to build one. Takes precedence over `redact_pii`.
</ParamField>

<ParamField path="debug" type="boolean" default={false}>
  If `True`, enable verbose debug logging via the `rdk` logger.
</ParamField>

<ParamField path="enabled" type="boolean" default={true}>
  If `False`, tracing is completely disabled and `init()` returns `None`. No SDK instrumentation occurs.
</ParamField>

<ParamField path="on_error" type="Callable[[Exception], None]" default="None">
  Callback invoked when a transport error occurs.

  Example: `lambda e: logger.error(f"RDK error: {e}")`
</ParamField>

<ParamField path="instrument_langchain" type="boolean" default={true}>
  If `True`, auto-instrument LangChain calls.
</ParamField>

<ParamField path="instrument_anthropic" type="boolean" default={true}>
  If `True`, auto-instrument Anthropic SDK calls.
</ParamField>

<ParamField path="instrument_openai" type="boolean" default={true}>
  If `True`, auto-instrument OpenAI SDK calls.
</ParamField>

<ParamField path="instrument_gemini" type="boolean" default={true}>
  If `True`, auto-instrument Google Gemini SDK calls.
</ParamField>

<ParamField path="transport" type="string" default="\"http\"">
  Transport backend. `"http"` sends to the collector; `"null"` discards all spans (useful for tests).
</ParamField>

<ParamField path="test_mode" type="boolean" default="None">
  If `True`, sets `transport="null"` and configures default tool mocks. Also reads from the `RDK_TEST_MODE` environment variable (`1`, `true`, `yes`).
</ParamField>

## Returns

The initialized `RDK` client instance, or `None` if `enabled=False`.

## Examples

### Zero-config

Set `RDK_API_KEY` and just use `@observe` — no `init()` needed:

```python
from rdk import observe

@observe()
def my_pipeline():
    ...
```

### Custom config

```python
from rdk import init

init(
    sample_rate=0.1,
    redact_pii=True,
    on_error=lambda e: logger.error(f"RDK error: {e}"),
)
```

### Testing

```python
from rdk import init

init(test_mode=True)  # No HTTP calls; tool calls return "MOCKED"
```

### Disable tracing entirely

```python
from rdk import init

init(enabled=False)
```

## Behavior

When called, `init()`:

1. Resolves `api_key` from argument or `RDK_API_KEY` env var
2. Resolves `endpoint` from argument, `RDK_ENDPOINT` env var, or default collector
3. Resolves `test_mode` from argument or `RDK_TEST_MODE` env var
4. Creates a singleton `RDK` client
5. Starts the background flush timer
6. Instruments the enabled LLM SDKs

If `enabled=False`, none of the above occurs and `None` is returned.

## Environment Variables

| Variable | Effect |
|----------|--------|
| `RDK_API_KEY` | API key (used when `api_key` is not passed) |
| `RDK_ENDPOINT` | Collector URL override |
| `RDK_TEST_MODE=1` | Equivalent to `test_mode=True` |
