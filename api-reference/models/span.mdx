## SpanType Enum

```python
class SpanType(str, Enum):
    LLM = "LLM"           # Language model calls
    CHAIN = "CHAIN"       # Orchestration logic
    TOOL = "TOOL"         # Tool/function execution
    FUNCTION = "FUNCTION" # Custom function spans
```

## SpanStatus Enum

```python
class SpanStatus(str, Enum):
    RUNNING = "RUNNING"   # In progress
    SUCCESS = "SUCCESS"   # Completed successfully
    ERROR = "ERROR"       # Failed with error
```

## Methods

### complete()

Mark span as successfully completed:

```python
span.complete(
    output={"result": "success"},
    token_usage=TokenUsage(
        prompt_tokens=100,
        completion_tokens=50,
        total_tokens=150
    )
)
```

`token_usage` is optional.

### fail()

Mark span as failed:

```python
span.fail(
    error_message="API timeout",
    stack="Traceback (most recent call last)..."  # optional
)
```

## Creating Custom Spans

Use the `span()` context manager — it handles `complete()` and `fail()` automatically:

```python
from rdk import observe, span
from rdk.models import SpanType

@observe()
def my_pipeline(query: str):
    with span("my-operation", span_type=SpanType.FUNCTION, input_data={"query": query}) as s:
        result = do_work(query)
        s.metadata["result_size"] = len(result)
    return result
```

See [span()](/api-reference/span) for full documentation.

## Auto-captured Metadata

RDK automatically captures provider-specific metadata for LLM spans.

### Common Fields (all providers)

| Field | Type | Description |
|-------|------|-------------|
| `provider` | string | Provider name (`anthropic`, `openai`, `google`) |
| `cost` | object | Cost breakdown (see below) |

### Cost Object

Automatically calculated for supported models:

| Field | Type | Description |
|-------|------|-------------|
| `total_cost` | float | Total cost in USD |
| `input_cost` | float | Cost of input tokens |
| `output_cost` | float | Cost of output tokens |
| `cache_read_cost` | float | Cost of cached token reads |
| `cache_write_cost` | float | Cost of cache creation |
| `cache_savings` | float | Amount saved from caching |
| `currency` | string | Always `"USD"` |

### Anthropic-specific

| Field | Type | Description |
|-------|------|-------------|
| `provider_request_id` | string | Anthropic's request ID for debugging |
| `cache_read_tokens` | int | Tokens read from prompt cache |
| `cache_creation_tokens` | int | Tokens written to prompt cache |

### OpenAI-specific

| Field | Type | Description |
|-------|------|-------------|
| `provider_request_id` | string | OpenAI's request ID (`x-request-id` header) |
| `reasoning_tokens` | int | Tokens used for reasoning (o1/o3/o4 models) |
| `cache_read_tokens` | int | Tokens read from cache |
| `system_fingerprint` | string | Model version fingerprint |
| `service_tier` | string | Service tier used (e.g., `"default"`, `"scale"`) |

### Gemini-specific

| Field | Type | Description |
|-------|------|-------------|
| `model_version` | string | Exact model version used |
| `cached_content_token_count` | int | Tokens from cached content |
| `safety_ratings` | array | Content safety ratings with category and probability |
