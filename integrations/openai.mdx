## Basic Usage

RDK automatically instruments the OpenAI SDK when initialized. Tracing works with or without `@observe`:

<CodeGroup>
```python Without @observe
from openai import OpenAI
from rdk import init, shutdown

init()

client = OpenAI()
response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role": "user", "content": "Write a haiku about programming"}]
)
print(response.choices[0].message.content)

shutdown()
```

```python With @observe
from openai import OpenAI
from rdk import observe, shutdown

@observe(name="openai-chat")
def chat(message: str) -> str:
    client = OpenAI()
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": message}]
    )
    return response.choices[0].message.content

result = chat("Write a haiku about programming")
print(result)

shutdown()
```
</CodeGroup>

<Note>
Without `@observe`, each API call creates its own trace. With `@observe`, all calls within the function are grouped into a single trace.
</Note>

## Async Support

RDK supports async OpenAI calls:

```python
import asyncio
from openai import AsyncOpenAI
from rdk import observe, shutdown

@observe(name="async-openai")
async def async_chat(message: str) -> str:
    client = AsyncOpenAI()
    response = await client.chat.completions.create(
        model="gpt-4o",
        messages=[{"role": "user", "content": message}]
    )
    return response.choices[0].message.content

result = asyncio.run(async_chat("Hello!"))
shutdown()
```

## Tool Calling

RDK captures OpenAI function/tool calls:

```python
import json
from openai import OpenAI
from rdk import observe, shutdown

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_stock_price",
            "description": "Get current stock price",
            "parameters": {
                "type": "object",
                "properties": {
                    "symbol": {"type": "string", "description": "Stock symbol"}
                },
                "required": ["symbol"]
            }
        }
    }
]

def get_stock_price(symbol: str) -> str:
    # Mock implementation
    prices = {"AAPL": 150.00, "GOOGL": 140.00, "MSFT": 380.00}
    return json.dumps({"symbol": symbol, "price": prices.get(symbol, 0)})

@observe(name="stock-agent")
def stock_agent(question: str) -> str:
    client = OpenAI()
    messages = [{"role": "user", "content": question}]

    response = client.chat.completions.create(
        model="gpt-4o",
        messages=messages,
        tools=tools
    )

    # Handle tool calls
    while response.choices[0].message.tool_calls:
        tool_calls = response.choices[0].message.tool_calls
        messages.append(response.choices[0].message)

        for tc in tool_calls:
            args = json.loads(tc.function.arguments)
            result = get_stock_price(args["symbol"])
            messages.append({
                "role": "tool",
                "tool_call_id": tc.id,
                "content": result
            })

        response = client.chat.completions.create(
            model="gpt-4o",
            messages=messages,
            tools=tools
        )

    return response.choices[0].message.content

result = stock_agent("What's Apple's stock price?")
shutdown()
```

## What Gets Captured

For each OpenAI call, RDK captures:

| Field | Description |
|-------|-------------|
| `model` | Model name (e.g., gpt-4o) |
| `input.messages` | Input messages |
| `output.choices` | Response choices with content |
| `output.tool_calls` | Function calls (if any) |
| `token_usage` | Prompt, completion, and total tokens |
| `metadata.provider` | "openai" |
| `metadata.provider_request_id` | OpenAI's `x-request-id` header |
| `metadata.cost` | Cost breakdown (total, input, output, cache) |
| `metadata.reasoning_tokens` | Reasoning tokens (o1/o3/o4 models) |
| `metadata.cache_read_tokens` | Tokens read from cache |
| `metadata.system_fingerprint` | Model version fingerprint |
| `metadata.service_tier` | Service tier (e.g., "default", "scale") |
| `metadata.max_tokens` | Max tokens parameter |
| `metadata.temperature` | Temperature parameter |
| `metadata.top_p` | Top-p parameter |
| `metadata.frequency_penalty` | Frequency penalty |
| `metadata.presence_penalty` | Presence penalty |

## Cost Tracking

RDK automatically calculates costs for all OpenAI models:

```json
{
  "cost": {
    "total_cost": 0.000035,
    "input_cost": 0.000010,
    "output_cost": 0.000025,
    "cache_read_cost": 0.0,
    "cache_write_cost": 0.0,
    "cache_savings": 0.0,
    "currency": "USD"
  }
}
```

See [Cost Tracking](/features/cost-tracking) for supported models and pricing details.

## Reasoning Tokens (o1/o3/o4 Models)

For reasoning models (o1, o3, o3-mini, o4-mini), RDK captures `reasoning_tokens`:

```python
from openai import OpenAI
from rdk import init, shutdown

init()

client = OpenAI()
response = client.chat.completions.create(
    model="o3-mini",
    messages=[{"role": "user", "content": "Solve: 2x + 5 = 15"}]
)

shutdown()
```

The span metadata includes:

```json
{
  "reasoning_tokens": 150,
  "cost": {
    "total_cost": 0.00066,
    ...
  }
}
```

Reasoning tokens are included in the total token count and cost calculation.
